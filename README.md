# Grimorio

App personal para la colección y los decks de Magic: The Gathering (Commander y Standard). Usa la API de Scryfall para cartas, imágenes y precios.

Abrir: https://francogylling.github.io/grimorio/

Los datos (colección, decks, ajustes) se guardan solo en el navegador de cada dispositivo. Para pasarlos de un dispositivo a otro se usa **Ajustes → Respaldo** y **Restaurar**.
